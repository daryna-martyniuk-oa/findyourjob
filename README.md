# FindYourJob

Сайт пошуку IT-вакансій для віддаленої роботи. Дані беруться з публічного API [Jobicy](https://jobicy.com).

## Можливості

- Головна сторінка з пошуком і швидкими тегами
- Каталог вакансій з пошуком, фільтрами за регіоном, рівнем і типом зайнятості, сортуванням
- Пошук і фільтри синхронізуються з URL, тож посиланням можна ділитися
- Збережені вакансії (зберігаються в браузері)
- Сторінка вакансії з описом і посиланням на оригінал
- Світла і темна тема, адаптивний дизайн, доступність (клавіатура, скрін-рідери)

## Стек

TypeScript, Vite, CSS (custom properties, `@layer`), DOMPurify, Vitest, ESLint, Prettier.
Без UI-фреймворків.

## Запуск

```bash
npm install --legacy-peer-deps
npm run dev        # режим розробки
npm run build      # збірка в dist/
npm run check      # типи, лінтер, форматування, тести
```

Щоб працювати без доступу до API, встановіть `VITE_USE_FIXTURE=true` (використовується локальний знімок вакансій у `public/fixtures/`).

## Тести

Логіка фільтрів, сортування, API та кеш, нормалізація даних, безпека HTML, інтеграційні тести сторінок і перевірка доступності.

## Структура

- `index.html`, `jobs.html`, `job.html` — сторінки
- `src/api/` — запити до API, кеш, нормалізація даних
- `src/pages/` — логіка сторінок
- `src/components/` — картки, скелетони, стани
- `src/utils/` — фільтрація, сортування, формати, геологіка
- `src/styles/` — стилі
- `tests/` — тести
